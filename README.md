# HAML-ET
Human Activity Machine Learning project with Extensive Training

## Reproducible XGBoost evaluation

Run the nested subject-grouped evaluation with:

```bash
python modelling/xgboost_nested_cv.py
```

See [the evaluation guide](modelling/xgboost_nested_cv.md) for the protocol,
input logs, generated report, automatic resume behavior, incremental checkpoints,
and interpretation caveats.
